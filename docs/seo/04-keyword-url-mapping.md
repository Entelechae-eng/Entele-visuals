## 1. Core Principles of Information Architecture

1. **One Primary Intent per URL:** Avoid cannibalization by ensuring each page targets a distinct primary user intent.
2. **Predictable, Clean Hierarchy:** Intuitive URL paths reflecting the resource taxonomy (`/components/:category`, `/templates/:platform`).
3. **Canonical Consistency:** Every page enforces a single canonical URL without trailing-slash variation.
4. **Contextual Internal Linking:** Category pages link down to individual items; item modals link across related categories and platforms.
